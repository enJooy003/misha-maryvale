# CHIHUAHUA GANG — Misha’s Story

Бесплатный браузерный прототип приключения Миши в Мэривейле. Первая глава: найди еду, познакомься с Луной, пройди гонку и найди дом.

## Управление

- iPad: джойстик слева; бег, прыжок и лай справа.
- Компьютер: WASD / стрелки, Shift — бег, Space — прыжок, E — лай, M — карта.
- Прогресс сохраняется в браузере.

## Запуск

Статический сайт: GitHub Pages, ветка `main`, папка `/ (root)`. Для локального запуска подойдет любой статический HTTP-сервер.

Нет серверных API, платежей, подписок, внешнего CDN или покупки моделей. Three.js 0.170.0 включён локально; его MIT-лицензия находится в `vendor/THREE-LICENSE.txt`.

Версия 0.2 — ранний прототип с процедурной графикой. Фотореалистичная графика и весь открытый мир из концепции ещё не реализованы. При недоступности WebGL используется упрощённая отрисовка Canvas.
